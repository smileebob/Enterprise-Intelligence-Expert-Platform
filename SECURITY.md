# Security Policy

## Supported versions

Security fixes are applied to the `main` branch and the latest release tag.

## Reporting a vulnerability

Preferred: GitHub private vulnerability reporting for this repository:

<https://github.com/smileebob/Enterprise-Intelligence-Expert-Platform/security/advisories/new>

If that entry is not enabled yet, open a minimal public issue asking the maintainers to enable a private channel. Do **not** include exploit details, credentials, personal data, or customer data in the public issue.

Please include:

- affected version/commit and deployment mode;
- reproduction steps using fictional data only;
- impact and whether the issue crosses authorization boundaries;
- any suggested fix.

## Scope notes

- Demo data is fictional. Do not test against real customer or production data.
- The project is not certified for regulated decision-making (legal, medical, investment, safety).
- Reports are handled on a best-effort basis; no SLA is promised.
