# 团队介绍 · 智涌

> 开源项目维护团队：**智涌**
> 项目：企业级领域专家 Agent 平台（AngentPlatform）

---

## 一、一句话定位

一支专注**企业级 AI 落地**的架构与工程团队：既能做顶层设计，也能写代码交付，擅长把「做得出演示」的 AI 概念变成「进得了生产」的企业系统。

## 二、团队能力画像

团队核心成员拥有 **20 年以上软件与互联网从业经验**，完整经历互联网、移动互联网、智能硬件（物联网）与企业人工智能四轮技术浪潮，职业履历覆盖**携程、平安健康、深兰科技、奥克斯集团**等企业，从一线研发工程师成长为集团级技术平台架构师。

团队能力覆盖本项目所需的全部关键环节：

### 1. 企业级系统架构

- 分布式系统与微服务架构（Spring Cloud / Dubbo）、DDD 领域驱动设计、高可用与容灾设计、系统性能工程；
- 主导过集团级技术中台建设：统一认证中心（OAuth2.0 + JWT，万级并发、海内外多节点部署，吞吐量提升 40%）、中间件平台（7 类中间件一键部署与全生命周期管理）、低代码平台（95+ 前后端组件沉淀）；
- 具备跨国多区域部署经验（中国、巴西、欧洲边缘节点），熟悉企业系统在真实组织中的落地约束。

### 2. 企业 AI 应用规划与工程化

- 正在负责覆盖 **11 个业务域、35+ AI 项目**的企业 AI 应用体系规划与推行，具备将 AI 能力嵌入企业真实业务流程的成熟经验；
- 设计过企业级 AI 统一服务框架：单一接口对接 GPT、通义千问、自建智能体平台等多供应商，支持无缝切换——本项目的模型网关（ModelGateway）设计即源于此实践；
- 深耕 AI 智能体设计与开发、知识库与 RAG 方案、AI 辅助开发体系建设，配套建立过「工具 + 规范 + 培训 + 评测门禁」的完整推进模式。

### 3. 知识工程与领域智能化

- 主导过基于 AI 大模型的智能实验室规划方案：论文要点提炼、实验方案梳理、多传感器联动预警——与本项目「专业知识检索与融合」场景同源；
- 主笔过 12 项编码规则 + 3 个 AI 测试智能体的开发规范体系，擅长把散落的领域经验沉淀为结构化、可执行、可复用的知识资产；
- 设计过通用化接口测试平台，基于业务抽象实现测试对象自发现，预留 AI 自动用例编写能力。

### 4. 全栈交付能力

- **后端**：Java（Spring Boot / Spring Cloud）、Python（FastAPI / Flask / Django）——本项目后端采用 FastAPI 0.115 + SQLAlchemy 2.0；
- **前端**：Vue 3 + TypeScript 独立工程交付——本项目前端采用 Vue 3.5 + Vite + Element Plus；
- **数据与中间件**：MySQL / Oracle / PostgreSQL / Redis / Kafka / RabbitMQ / EMQX、向量数据库与 RAG 方案；
- **DevOps**：Docker / Kubernetes / Jenkins / SkyWalking，一键起栈与可观测体系均为日常实践。

### 5. 智能硬件与机器人软件（早期积累）

- 主导过大型消毒机器人、送餐机器人、机场自回收电动车等项目的软件架构，在业务层与感知导航层之间创新增设安全控制层；
- 主导过企业基础架构整体演进（Nacos + SkyWalking + Sharding-JDBC + RabbitMQ + EMQX 中间件体系、核心服务容器化改造）。

## 三、团队与本项目的契合点

本项目「企业级领域专家 Agent 平台」不是一次性的演示型 Demo，而是团队日常工作的真实命题——**企业 AI 最大的痛点不是模型能力不够，而是「做得出演示，进不了生产」**。团队把在真实企业环境中验证过的方法搬进了这个项目：

| 真实工作中的实践 | 在本项目中的落位 |
|---|---|
| 多供应商大模型统一接入框架 | M0 抽象层 ModelGateway（OpenAI 兼容 / 离线确定性通道，降级 L0–L4） |
| 企业知识「外部通用知识覆盖内部专有知识」的真实事故教训 | KP-1 知识管道：六级信息分级 + 分区召回 + 融合冲突消解（CS-01~05） |
| AI 应用质量评测与流水线门禁 | M4 评估引擎：六维评分 + 大模型校准协议（±10 限幅 / >15 转人工）+ 双层护栏 |
| 研发规范体系与架构治理 | 12 项编码规则贯穿全代码库：140 项测试、覆盖率 87.10%、ruff / bandit 全绿 |
| 数据合规与权限管控实践 | 五类安全 Hook + BR-08 角色动态脱敏 + PIPL 个人记忆查阅 / 更正 / 删除 / 导出 |

## 四、工作方式

远程协作、文档先行、规范驱动：需求 → 设计 → 代码与测试 → 验收报告，全流程留痕。本仓库的文档结构与代码质量本身就是团队工程方法的直接体现。
