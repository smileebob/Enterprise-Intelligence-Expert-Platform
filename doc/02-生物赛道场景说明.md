# Track 03 · AI＋生物技术赛道 —— 场景理解与方案映射

> 本文档为参赛作品对**生物技术赛道（AI 产业招商专家）**的细部场景说明。
> 本赛道在参赛策略中为**副领域**：以「配置装配 + 轻量模拟数据」在同一平台底座上跑通端到端问答与六维画像，用于证明平台的**工程化潜力与规模扩展能力**（评审维度 04）——同一底座换套配置即可装配新领域，而非针对单一场景的定制 Demo。

## 一、官方赛题还原（已核验）

### 1.1 业务背景

传化科技城依托杭州萧山的区位优势与产业资源，面向**创新药、基因与细胞治疗、AI 制药、医疗器械及医美**等前沿生物技术领域，推动产业集聚与创新生态建设。围绕生物技术企业从园区入驻、成长发展到市场转化的全生命周期，科技城重点探索三大 AI+ 方向：

| 方向 | 内涵 |
|---|---|
| **AI+空间** | 前沿企业精准招商与智能落地：企业发现、招商洽谈、智能选址及入驻服务，提升招商效率与落地转化率 |
| **AI+服务** | 生物技术企业创新与成长赋能：研发创新、政策申报、融资对接及产业资源匹配 |
| **AI+市场** | 精准市场洞察与智能营销增长：市场机会识别、目标客户开发、渠道匹配及营销转化 |

传统产业园区运营高度依赖人工开展企业搜寻、招商对接及产业服务，面临**前沿企业发现难、产业资源匹配效率低、企业市场拓展能力不足**等挑战。

### 1.2 重点推荐场景：AI 产业招商专家

利用 AI 识别前沿生物技术企业，辅助企业招商与园区资源匹配。面对企业分布广、技术路线复杂、发展阶段差异大等特点，传统招商依赖人工开展产业研究、企业筛选与需求对接。官方建议探索三大能力：

| # | 官方能力要求 | 内涵 |
|---|---|---|
| ① | **前沿产业洞察与企业发现** | 整合工商、融资、专利、科研成果及产业动态等信息，识别前沿技术趋势、高潜力企业及潜在招商机会 |
| ② | **企业画像与招商需求识别** | 分析企业技术方向、融资阶段、研发需求及扩张动态，生成企业画像，识别潜在选址及入驻需求 |
| ③ | **园区资源智能匹配** | 结合企业发展需求与园区空间、政策及产业资源，辅助推荐适配的园区资源与招商策略，提升精准招商效率与转化率 |

### 1.3 其他创新方向（平台已预留扩展，实现路径见 §四）

AI 驱动的企业智能选址与落地方案（AI+空间）、AI 驱动的企业政策精准匹配（AI+服务）、AI 驱动的生物技术企业销量增长（AI+市场）。三个方向均未在本期 Demo 中实现，但副领域插件的工具与槽位声明中已为其预留挂点，**§四给出逐方向的实现路径与方案**。

## 二、场景 → 平台能力映射（副领域：轻量装配）

### 2.1 为什么用"装配"而非"重写"来打这个赛道

化学与生物招商在架构上**同构**：都是「多源知识（内部+外部）→ 领域理解 → 检索融合 → 画像/推理 → 方案生成」的专家型 Agent。本作品将招商专家实现为一个**领域插件**（`domains/investment`，轻量五要素：domain.yaml / prompts / tools / 评估 scorers / composer），与化学主领域共用同一套 M0–M9 底座。这本身就是对评审维度 04（工程化潜力与规模扩展）的直接回答：**新领域接入 = 一份领域配置 + 一批领域数据，不改底座代码**。

### 2.2 官方三大能力的平台落位

| 官方能力 | 平台机制 | 副领域实现 |
|---|---|---|
| ① 前沿产业洞察与企业发现 | KP-1 知识管道：工商/融资/专利/科研/动态多源知识统一入库、六级打标、分区召回 | 轻量模拟企业库（`data/investment_mock.json`）灌入知识底座；企业发现以检索+画像推理完成，**外部数据源实时接入为后续路径（见 §五局限）** |
| ② 企业画像与招商需求识别 | 编排引擎（澄清→规划→检索→融合→生成）+ **六维评估引擎跨领域复用**（化学：产品方案六维 → 招商：企业六维画像，场景权重画像配置化） | 企业六维画像开箱即用；评估标准层版本化，可随真实数据校准 |
| ③ 园区资源智能匹配 | 领域工具集（园区空间/政策/产业资源检索工具，MCP 同构 @tool 契约 + RBAC 权限）+ 融合生成招商策略建议 | 园区资源知识入库，对话中按企业需求匹配并给出带引用的推荐 |

平台级能力（六级信息分级、冲突消解、五类安全 Hook、四层记忆、自成长）对两个领域**同时生效**，无需重复建设——例如招商场景同样享受「内部园区数据优先于外部公开信息」「敏感招商线索按角色脱敏」「引用逐条可追溯」。

### 2.3 六维评估复用的关键证据

招商副领域**未重写任何评估代码**：打分器注册表 + 场景权重画像 + 双层护栏 + 大模型校准协议（±10 限幅 / >15 转人工）全部继承自底座；仅按领域配置了企业画像的六维定义与权重。评委可在装配台直接观察「领域上线 → 切换领域 → 企业六维画像输出」的完整过程。

## 三、评委可操作演示路径（约 3 分钟）

> 前置：同根 README §五（`init_demo.py` 已自动装配双领域）。

1. **领域装配（平台通用性主证据）**：`admin / Admin@12345` 登录 → 装配台查看「AI 产业招商专家」插件（可演示下线/上线/回滚）→ 五要素配置一目了然。
2. **招商问答与六维画像**：对话台切换领域为「AI 产业招商专家」→ 提问「帮我找 AI 制药赛道的高潜企业」→ 观察：检索园区/企业知识 → 输出企业六维画像 + 数据有限护栏标注（轻量数据下的诚实提示）+ 园区资源匹配建议 + 引用角标。
3. **权限与审计**：`auditor / Audit@12345` 登录审计台 → 按 trace_id 复原招商问答的「输入→检索→工具→输出」全链路 Hook 记录。
4. **对照主领域**：同一界面切回「AI 化学家」提问——同一底座、同一交互范式、不同领域知识与评估维度的直观对比。

## 四、官方三个创新方向的实现路径（平台扩展预留实证）

官方在重点推荐场景之外列出三个创新方向（AI+空间 / AI+服务 / AI+市场）。本节说明：**平台哪些机制已被直接复用（均有代码落位）、每个方向需新增什么、分几步落地、如何验证**。坦陈在前：生物赛道三方向比化学更依赖外部/真实数据接入，主要新增工作集中在数据对接，底座机制零改动。

### 4.1 AI 驱动的企业智能选址与落地方案（AI+空间）

> 官方描述：匹配研发空间、实验设施与政策资源，辅助生成企业落地方案。

**平台已预留（可直接复用）**：

| 复用点 | 代码落位 |
|---|---|
| 园区资源匹配工具**已上线**：按企业需求匹配园区空间/政策/产业资源 | `match_park_resources`（`domains/investment/tools/`） |
| 选址需求理解：澄清槽位声明中**已含「落地需求」**，插件声明式槽位、核心引擎不硬编码领域语义 | `domains/investment/domain.yaml: clarify_slots`（含 落地需求/政策需求） |
| 园区空间/设施/政策知识入库：六级打标，园区内部台账（internal）优先于外部公开信息，推荐逐条引用可溯源 | KP-1 知识管道 + `domains/investment` 知识绑定 |
| 落地方案评估：企业六维画像引擎 + 打分器插件点，方案可按适配维度打分排序 | `core/evaluation`、`core/domains.py: resolve_scorer` |

**需新增**：① 数据：园区空间台账（面积/层高/承重/排污/危废资质）、实验设施清单、租金与政策包（新 schema 沿用现有入库适配器模式）；② 选址匹配打分器（空间适配 × 设施适配 × 成本 × 政策叠加，注册为领域 scorer）；③ 落地方案 composer（沿用投资领域 composer 模式，模板化装配 + 引用，不自由生成）。

**实现路径**：阶段一（模拟台账 PoC）：对话式选址——"一家做细胞治疗的中试团队，需要 GMP 车间和危废处理，落在哪合适？"→ 槽位澄清 → 资源匹配 → 带引用的落地方案；阶段二：接入真实园区资源台账，方案进招商流程（人工确认后推送）；阶段三：落地全流程跟踪（签约→装修→入驻）状态机与里程碑提醒。
**验证方式**：历史招商案例回放（推荐资源与实际落位的一致度）+ 招商经理盲评方案可用率。

### 4.2 AI 驱动的企业政策精准匹配（AI+服务）

> 官方描述：匹配适用政策、评估申报资格并辅助生成申报材料。

**平台已预留（可直接复用）**：

| 复用点 | 代码落位 |
|---|---|
| 资质核实工具**已上线**（当前模拟数据源，**外部核实系统预留插口**——正是为本方向留的挂点） | `verify_qualification`（`domains/investment/tools/`） |
| **申报资格硬门槛的确定性判定**：与化学 CS-05 合规例外同构——资格条件（注册资本/研发投入占比/专利数）用确定性规则表执行，不下沉给大模型裁决 | 复用 `core/knowledge/compliance.py` 规则表模式 |
| 政策知识的内外部分级：政策原文（external）与园区内部解读/兑现口径（internal）分级入库，口径冲突时内部优先、双方保留标注 | 六级信息分级 + 融合冲突消解 |
| 资格评估输入：企业画像（技术方向/融资阶段/研发需求）即评估引擎已演示的六维画像输出 | `core/evaluation` + investment 画像配置 |
| 政策库更新监测：周期任务扫描（Celery beat 范例已存在）；每条申报建议强制引用政策条款原文 | `core/celery_app.py: beat_schedule`、输出 Hook 引用校验 |

**需新增**：① 数据：国家/省/市/园区各级政策库、申报指南、历史申报与兑现案例；② 资格条件规则表（按政策逐条配置硬门槛）；③ 申报材料 composer（模板化 + 引用装配：企业信息自动填位、佐证材料清单生成，关键表述留人工确认位）。

**实现路径**：阶段一（政策库 + 资格初筛）："我们这家 AI 制药 A 轮企业能报哪些政策？"→ 画像比对规则表 → 匹配清单 + 差距说明（哪条不满足、缺什么）；阶段二：真实政策库接入 + 申报材料辅助生成 + 人工审核流转；阶段三：申报进度跟踪 + 政策更新自动重匹配（新政策出台即圈定适配企业名单推送给招商/服务团队）。
**验证方式**：历史申报案例的资格判定一致率、生成材料的要件覆盖率与人工修改率。

### 4.3 AI 驱动的生物技术企业销量增长（AI+市场）

> 官方描述：识别高潜力客户、匹配销售渠道，支持营销转化与销量增长。

**平台已预留（可直接复用）**：

| 复用点 | 代码落位 |
|---|---|
| **客户发现 = 企业发现的能力对偶**：同一套「多源知识融合 + 画像推理」，视角从"招企业"换为"找买家"（下游应用企业：医院/药企/CRO/器械经销商） | `search_enterprises` 工具与企业库模式 |
| 线索评分：画像引擎复用——评分维度/权重按场景配置（打分器插件点 + 场景权重画像机制） | `core/evaluation` 打分器注册表模式 |
| 渠道资源匹配：与园区资源匹配同一工具模式（@tool 契约 + RBAC） | `match_park_resources` 模式复用 |
| 转化结果回流：营销转化 outcome → 正负样本 → 画像权重与标准层版本化迭代 | `core/growth` 自成长闭环 |

**需新增**：① 数据：下游客户库（机构类型/采购方向/规模/历史采购）、渠道资源台账、历史转化数据；② 线索评分规则（初版规则式：需求匹配度 × 采购能力 × 时机信号；P2 可训练转化预测分类模型并以 `ai_inferred` 分级注入）；③ 营销触达内容模板（受控模板 + 引用，敏感客户信息按角色脱敏——BR-08 机制现成）。

**实现路径**：阶段一（模拟客户库）："做医美器械的企业，华东有哪些高潜买家？"→ 客户发现 + 线索评分排序 + 触达建议；阶段二：接入 CRM 真实客户与转化数据，渠道匹配建议进销售流程；阶段三：转化漏斗跟踪 + 评分规则迭代（自成长闭环），形成"园区帮企业卖产品"的增值服务叙事。
**验证方式**：历史转化数据回测（评分排序的 Top-N 命中率）+ 销售团队采纳率统计。

## 五、数据说明与当前局限（务实声明）

- **数据**：副领域使用轻量模拟企业库（虚构企业/融资/专利信息，`is_mock` 显式标注）。我们刻意**不套用真实企业名称+虚构融资/专利数据**——虚构企业的"发现"无意义，套真名造假则会被质疑，因此演示重点放在「画像与匹配的能力范式」而非「发现结果本身」。
- **局限 1（最重要）**：官方能力①中的「实时整合工商、融资、专利、科研、产业动态等外部数据源」当前以预置模拟库代替，未接入真实外部数据源（如工商/专利/投融资数据 API）。平台侧的对接预留：知识入库管道支持新增解析适配器、模型网关与工具网关支持新增外部数据工具（防腐层模式），接入工作量集中在数据源对接与实体消歧两处。
- **局限 2**：企业六维画像的维度与权重为经验设定，未经真实招商转化数据校准；评估标准层版本化机制已就绪，真实数据到位后可走「草稿→审核→发布」流程迭代。
- **局限 3**：实体消歧（同名企业、集团-子公司关系）是真实数据接入后的已知难点，当前轻量库未覆盖。
- **终赛路径**：若晋级，将按赛事方提供的真实业务需求与数据，优先补齐「外部数据源接入 + 实体消歧」，复用现有知识管道与评估引擎完成端到端验证。
