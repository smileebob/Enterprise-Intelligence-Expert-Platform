## 三、合规声明

1. **原创性**：本作品代码、文档、模拟数据均为团队原创；使用开源组件的部分已在 `doc/04-技术实现说明.md` §四 明示组件名称、用途与 License。
2. **模拟数据标注**：初赛阶段全部演示数据为赛事模拟数据（产品名/型号/专利号/DOI/数值均虚构），界面与 API 响应中以 `is_mock` 显式标注，文档中亦逐处说明；不得用于任何生产决策。
3. **人工操作环节**：演示账号口令为种子数据（仅演示用途）；评估结果的人工确认/修正为标准产品功能（人机协同设计），非评审材料的人工修饰。
4. **知识产权**：已知悉并同意官方要求——参赛后提交作品的知识产权归主办方所有。
5. **数据安全**：仓库不含任何真实业务数据、真实密钥或第三方保密信息；`.env` 等密钥文件已纳入 `.gitignore` 不入库。

## 五、评审与后续安排（官方流程备忘）

1. **初赛评审**：评委会结合代码、README 及支撑材料综合评价，必要时联系团队核实技术实现及测试结果——保持联系方式畅通；
2. **方案打磨**：赛事方为晋级团队提供细化业务需求与真实业务数据——对接预案见 `doc/01` §四、`doc/02` §四；
3. **决赛路演**：现场 PPT 路演与答辩，可辅以 Demo 演示——本仓库的 5 分钟演示脚本（根 README §5.4）可直接作为路演演示主线。

**数据保密承诺**：晋级后获得的赛事方真实业务数据，将严格以赛事方数据使用规则和保密要求为准，未经书面许可不向第三方披露、不上传外部平台、不用于本赛事以外用途。
