# 政务智能体部署运行与回退说明

> 适用于当前参赛演示版本，不是生产加固认证。  
> 实测环境：Windows、Python 3.12、Node.js、SQLite 与进程级 Celery eager。  
> Docker Compose 不作为本机验证前提；下述本地等价路径已实际用于联调。

## 一、可重建演示环境

### 1. 后端

在 `platform/` 目录：

```bash
python -m venv .venv
./.venv/Scripts/activate
pip install -r requirements.txt
```

创建独立演示库，避免与开发库混用：

```bash
DATABASE_URL=sqlite:///../_tmp/gov_demo.db ./.venv/Scripts/python.exe -m alembic upgrade head
DATABASE_URL=sqlite:///../_tmp/gov_demo.db ./.venv/Scripts/python.exe scripts/init_gov_demo.py
DATABASE_URL=sqlite:///../_tmp/gov_demo.db DEMO_MODE=offline ./.venv/Scripts/python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000
```

`init_gov_demo.py` 会导入两份国务院公开政策条款，执行工程演示审核并建立检索向量。输出的
`review_kind=engineering_fixture_not_human_review` 必须保留：它不代表真人完成政策复核。

### 2. 前端

在 `platform-web/` 目录：

```bash
npm install
npm run dev -- --host 127.0.0.1
```

访问 `http://127.0.0.1:5173/#/login`。演示可使用种子账号，但生产部署必须覆盖所有种子口令。

### 3. 独立演示验收

已完成的环境重建验证包括：

- 空 SQLite 库执行六个政务迁移到 head；
- 公开政策初始化可重复执行，重复时保持幂等；
- 后端 350 项全量测试、覆盖率 87.70%（以最终回跑日志为准）；
- 前端 `npm run typecheck` 与 `npm run build` 通过；
- 真实浏览器验证政策解读、公文、总结、咨询、审核、版本对照、无权限和失败提示。

## 二、故障与降级

| 场景 | 预期行为 | 验证方式 |
|---|---|---|
| 模型或查询向量失败 | 政策检索退回词面，响应标注非 hybrid | 禁用网络或模拟模型异常 |
| 向量未建 | 词面检索仍可用，不伪装混合检索 | 不对版本执行 embeddings |
| 政策接口失败 | 前端提示“网络异常，请稍后重试” | 浏览器拦截接口 |
| 未审核 DOCX | 返回 409，不生成下载 | 导出未审草稿 |
| 含手机号/身份证号 | 返回阻断，不生成 ZIP | 导出带敏感号码草稿 |
| 无权限访问 /gov | 跳转无权限页，不循环重定向 | 安全审计员访问 |
| 服务重启 | 政策、草稿、会话、审计保存在数据库，可重新登录继续 | 停止并重启 uvicorn 后复查 |

## 三、回退

1. 停止后端和前端进程；
2. 代码回退到上一已验收 commit，不使用未记录的生产目录热改；
3. 数据库迁移按实际版本执行 `alembic downgrade <上一版本>`；六个政务迁移均已在临时库验证降级和再升级；
4. 配置通过环境变量恢复，不把生产密钥写入代码或 `.env` 提交；
5. 保留政策原文、审核记录和导出证据包；不得以删除业务数据作为故障绕过；
6. 重启后执行 `/healthz`、`/readyz`、政策初始化查询和 `/gov` 主路径冒烟。

## 四、生产部署前置

- 使用正式数据库与密钥管理，关闭默认演示账号；
- 配置 HTTPS、CORS 白名单、日志留存、备份恢复和监控告警；
- 设计政务云/本地化部署时，逐项实测操作系统、数据库、模型运行时、浏览器和信创软硬件；
- 当前没有完成信创认证、真实政务云部署或真实机关试用，不得在材料中声称已满足这些条件；
- 不接入国家秘密；真实敏感数据接入前完成分类分级、授权、脱敏和专项评估。

## 五、已验证边界

- 本说明描述的是演示版进程级启动与故障行为，不是高可用生产架构；
- 单位内部公文版式、签章、用印、公文交换和 OA 归档不在当前范围；
- 文稿与总结为抽取式，政策解读为条款摘录，DOCX 为草稿包，均不替代正式签发和公开发布。
