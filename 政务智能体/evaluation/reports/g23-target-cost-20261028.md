# G-23 目标验证与成本折算（公开样本初筛）

> 日期：2026-10-28  
> 数据：公开政策草案集 15 条 × 3 次 × 3 个模型；只发送公开政策条款和公开/合成问题。  
> 结论：公开云模型端点、版本固定和数据边界可验证；私有化/目标政务云和 PostgreSQL 实跑仍缺环境，不能称生产目标验证完成。

## 一、目标验证

| 项目 | 结果 | 证据 |
|---|---|---|
| 模型端点可用 | PASS：对话 200、嵌入 200，1024 维 | `check_gov_model_readiness.py --probe` |
| 对话模型 | `qwen3.8-max`、`qwen3.8-flash`、`deepseek-v4.1-flash` | 15 条 × 3 次全量运行 |
| 版本固定候选 | `qwen3.8-max-0902` 200（约 2.3s）；`deepseek-v4.1-flash-1017` 200（约 1.4s） | 单次探测；flash 账户内未发现快照 ID |
| 调用稳定性 | 135 次调用无传输错误；各模型 outcome 稳定 15/15 | `reports/repeat-20261028T035901Z.*` |
| 时延 | 中位：max 10.3s、flash 6.5s、deepseek 2.3s | 同上 |
| 数据边界 | 只发送公开政策条款和公开/合成问题，无个人信息、内部材料或密钥 | 评测脚本与样本 |
| 私有化部署 | 未验证：只有公有云端点，无私有化/专有部署地址 | 环境限制 |
| 目标数据库 | 部分：SQLite 本机已跑；PostgreSQL/pgvector 无实例，未实跑 | 见下 |
| 信创/政务云环境 | 未验证：无目标环境账号、机器和网络 | 环境限制 |

### 数据库迁移检查

- Alembic 迁移包含 `CREATE EXTENSION vector`、`VECTOR(1024)`、`TSVECTOR` 和 HNSW 索引。
- 使用 PostgreSQL URL 做离线 SQL 渲染，可生成 35 张表和向量/全文结构；随后被一个需要数据库连接的数据迁移中断（离线 bind 为空），不能替代在线 PG 执行。
- 本机没有 PostgreSQL 服务，也没有 Docker；因此 PostgreSQL + pgvector 的真实建表、查询、HNSW 和 `plainto_tsquery` 结果集仍是 BLOCKED。

### 实际 tokens 与费用

| 模型 | 调用数 | 输入 tokens | 输出 tokens | 费用（元） |
|---|---:|---:|---:|---:|
| qwen3.8-max | 45 | 22,668 | 17,118 | 0.888264 |
| qwen3.8-flash（非思考） | 45 | 22,668 | 15,233 | 0.054694 |
| deepseek-v4.1-flash（忙时） | 45 | 22,275 | 10,288 | 0.126854 |
| text-embedding-v3（94 条款全量建向量） | 10 批 | 6,789 | — | 0.003394 |

- 本轮完整评测（45 次/模型 + 全量嵌入）主口径：**1.073206 元**。
- 区间：flash 按思考输出、deepseek 按闲时，约 **1.010–1.159 元**。
- 折算到 15 条单次评测：约 **0.358 元**（区间 0.337–0.386 元）。
- 单次问答：max 约 **0.0197 元**、flash 约 **0.0012 元**、deepseek 约 **0.0028 元**。
- 1,000 次问答：max 约 **19.74 元**、flash 约 **1.22 元**、deepseek 约 **2.82 元**（按本轮平均上下文和输出长度，实际随材料长度变化）。

### 观察

- 费用主要由 qwen3.8-max 输出 tokens 决定；flash/deepseek 便宜一个数量级，但本轮质量同为 13/15。
- 嵌入全量建索引仅约 0.0034 元，可忽略；重复重建会线性增加。
- 成本结论只对应公开草案集和当前提示词/上下文；真实公文长度、重试和审核返工会增加费用。

## 三、结论与限制

1. 公有云模型端点和数据边界可验证，版本固定建议使用 `qwen3.8-max-0902` 等快照并在目标环境重跑。
2. 目标政务云、私有化部署、PostgreSQL/pgvector、信创适配仍无法在本机验证，G-23 保持 IN_PROGRESS。
3. 成本只按官方目录价和 tokens 折算，未对账；正式申报不写金额节约或采购结论。
