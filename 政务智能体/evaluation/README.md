## 分桶

评测分为政策解读、版本适用、公文起草、事实核对、提炼总结、政务咨询和安全分流。每桶同时包含正例、边界和陷阱；高风险样本单列，不以总体平均分掩盖。

## 标签

样本 JSON 遵守 `cases.schema.json`。`data_kind` 区分公开、合成和经授权脱敏数据，禁止混报。`expected.outcome` 明确系统应回答、澄清、说明不足、转审或阻断，防止把“勉强回答”算作正确。

## 数据隔离

- 开发集用于规则与提示词调整；
- 最终测试集按来源文件分组隔离，同一文件的条款不得跨集泄漏；
- 使用反馈或公开样本调参后，相关样本不再作为最终测试的独立证据；
- 任何金标变化保留变更日志和影响说明。

当前公开政策只有一组文件，两个版本同属一个来源组，全部放在测试集；合成开发集不含该文件条款。首轮结果已用于校准，因此不能称为独立测试。

## 评分

自动检查引用、版本、格式、数字和权限；人工检查适用条件、内容完整性、表达和可用性。人工盲评隐藏方案名称，记录分歧与仲裁。模型评审只能作为辅助，不替代最终测试集上的人工判据。

自动运行只覆盖可字面判定的部分，不能替代人工对“是否真正回答了问题”的判断。
