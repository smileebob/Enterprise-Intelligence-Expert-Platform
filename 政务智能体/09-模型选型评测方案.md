# 模型与嵌入选型评测方案

> 版本：v1.1（评测方案 + 公开样本初筛，不是选型结论）  
> 当前状态：IN_PROGRESS。已完成公开草案集三模型初筛、完整 15 条 × 3 次重复、支持性消融和嵌入回归；仍缺独立人工复核、金额成本折算和私有化/目标环境，不能给出正式排名或采购结论。  
> 当前生产演示默认使用离线确定性通道，仅用于机制与流程复现，不代表真实大模型质量。

## 一、评测目标

在同一批政务样本、同一权限和同一输出契约下，比较候选模型在政策解读、公文草稿、文稿总结和咨询拟稿上的质量、稳定性、时延、成本与数据发送边界，为部署选型提供可复核依据。

选型不是只看通用榜单，也不以单次演示或模型自评替代业务判据。

## 二、候选与数据

候选项至少包括：

- 可私有化部署的中文通用模型；
- 经合规审批的政务云模型；
- 当前离线确定性通道，仅作为可复现基线；
- 两套以上嵌入模型，用于比较中文政策条款召回。

数据使用独立政务验证集，按来源文件划分开发、验证和最终测试集。样本必须包含历史版本、尚未施行、已废止、对象例外、证据不足、冲突、公文结构和敏感分流。禁止用开发集结果冒充最终测试结果。

真实政策、公文和咨询材料需获授权并脱敏；当前无真实试点数据，G-25 金标集建立前不得执行正式选型排名。

## 三、评测维度

| 维度 | 指标 |
|---|---|
| 政策适用 | 版本选择准确率、失效政策误用率、冲突揭示率 |
| 证据支持 | 条款引用正确率、无依据确定结论率、拒答合理性 |
| 公文质量 | 文种结构通过率、数字事实一致率、人工可用率 |
| 文稿总结 | 必保留要点覆盖率、任务与原文映射完整率 |
| 稳定性 | 同版本重复一致性、Schema 合法率、超时与降级率 |
| 性能 | P50/P95 时延、tokens、单任务成本、并发资源 |
| 安全 | 数据是否出境、日志留存、密钥隔离、提示注入抗性 |
| 部署 | 私有化、国产化硬件/系统适配、版本固定与回退 |

## 四、实验方法

1. 固定知识快照、提示词、规则、模板和评测集版本；
2. 每个模型至少运行三次，报告中位数、离散度和失败样本；
3. 真实模型与离线通道结果分表呈现，不混算平均分；
4. 引用与数字用确定性检查，政策解释和文稿可用性用人工盲评；
5. 嵌入模型更换时重建独立索引，记录 embedding_model，禁止跨语义空间混检；
6. 模型失败不得默认放行高风险输出，记录降级层级与转人工结果。

## 五、当前可执行部分

- 离线通道可复跑：作为功能基线和降级对照，不能作为真实模型质量结论；
- 政务验证接口、固定输出结构和支持性检查已具备；
- 模型网关支持 OpenAI 兼容端点、超时、重试、熔断和报告模型别名。

## 六、阻塞与解除条件

阻塞原因：

- 无独立人工复核的政务金标集；当前只有开发者自检草案；
- 无目标政务云/本地化硬件环境，无法做真实时延、私有化和信创适配测试；
- 尚未按同一模型重复三次并统计中位数/离散度；
- 未折算金额成本，未做支持性检查门禁消融。

已解除：

1. 已取得百炼模型 API Key，并验证对话与嵌入端点可用；
2. 已在公开政策草案集上完成三模型初筛（见下节）。

仍缺：

- 独立人工复核的政务金标集；
- 金额成本折算（当前只记录 tokens）；
- 私有化和目标政务云环境的时延、资源与安全验证。

解除条件：

1. 完成 G-25 金标集的独立复核并冻结最终测试集；
2. 获得模型服务和数据处理授权，固定候选模型版本、部署参数和计费口径；
3. 在目标环境完成至少三次重复、压测、故障注入和安全审查。

解除前不得把候选模型称为“最佳”或“已选型”；申报材料只能写“可替换模型网关与离线基线，已完成公开样本初筛”。

## 七、真实凭证与公开样本初筛

### 7.1 凭证类型

模型推理需要的是**百炼/DashScope API Key**（形如 `sk-...`），不是阿里云 AccessKey ID/Secret。AccessKey 用于云资源 OpenAPI，不能直接替代模型 API Key。

本地配置（`platform/.env`，已被 Git 忽略）：

```env
DEMO_MODE=live
LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
LLM_API_KEY=<百炼 API Key>
LLM_MODEL=qwen3.8-max
EMBED_MODEL=text-embedding-v3
EMBED_DIM=1024
```

自检命令：

```bash
cd platform
./.venv/Scripts/python.exe scripts/check_gov_model_readiness.py
./.venv/Scripts/python.exe scripts/check_gov_model_readiness.py --probe
```

`--probe` 只发送“只回复 OK”和一条“测试”嵌入，不发送任何业务材料；会产生少量费用。

### 7.2 探测结果（2026-10-28）

| 项目 | 结果 |
|---|---|
| 对话 `qwen3.8-max` | 200，首次约 1.8 秒 |
| 嵌入 `text-embedding-v3` | 200，1024 维，约 0.15 秒 |
| 其他可用嵌入 | `qwen3.7-text-embedding-flash`、`qwen3.7-text-embedding`，均 1024 维 |

### 7.3 公开样本初筛（不是选型）

数据：公开政策测试集 15 条，全部 `label_status=draft`；只发送公开政策条款和公开/合成问题。

| 方案 | 通过/分母 | 平均时延 | 输入/输出 tokens |
|---|---|---|---|
| 离线抽取 | 15/15 | — | — |
| 朴素词面检索 | 4/15 | — | — |
| qwen3.8-max + 检索 | 13/15 | 12.3 s | 7556 / 5612 |
| qwen3.8-flash + 检索 | 13/15 | 6.1 s | 7556 / 5123 |
| deepseek-v4.1-flash + 检索 | 13/15 | 2.8 s | 7425 / 4049 |

逐条检查发现，两个模型的“失败”中至少两条是字面判据误伤：否定句“不收取检索、复制、邮寄等成本费用”仍含禁用短语；澄清用“地区”而判据要求“政策地区”。自动分未调整，人工复核后可能变化。

结论：三个模型都能在版本边界、旧版费用、补正期限、年度报告等陷阱上给出带正确版本引用的回答；时延差异明显，但样本小、无独立复核，不能据此选型。

### 7.4 重复一致性与支持性消融

完整 15 条公开草案样本，每个模型 3 次：

| 模型 | 三次全过 | 至少一次通过 | outcome 稳定 | 中位时延 |
|---|---|---|---|---|
| qwen3.8-max | 13/15 | 13/15 | 15/15 | 10.3 s |
| qwen3.8-flash | 13/15 | 14/15 | 15/15 | 6.5 s |
| deepseek-v4.1-flash | 13/15 | 13/15 | 15/15 | 2.3 s |

支持性消融：对模型 claims 做确定性条款支持检查，`direct/partial` 接受，`insufficient` 降级。三个模型都从原样 13/15 降到 9/15。主要原因是词面覆盖检查对同义改写过严，而不是模型引用了错误版本。该结果说明：LLM 输出需要语义支持复核或人工复核，不能只用字面门禁。

### 7.5 嵌入回归与批量修复

发现 `text-embedding-v3` 单请求最多 10 条，`qwen3.7-text-embedding` 最多 25 条；原实现一次提交全部条款，超限后会回退离线哈希嵌入。已改为统一按 10 条分批，并新增 Phase 33 测试。

三种嵌入在 12 条有明确引用要求的样本上，混合检索均 12/12 命中要求引用和版本；平均检索时延：`text-embedding-v3` 236.6ms、`qwen3.7-text-embedding-flash` 164.7ms、`qwen3.7-text-embedding` 181.0ms。该对比含词面分数，不是纯向量召回，也不是正式嵌入选型。

### 7.6 凭证安全

- 百炼 API Key 只写入本地 `.env`，`.env` 已被 `.gitignore` 忽略，不进入仓库、日志或申报材料。
- 阿里云 AccessKey ID/Secret 已在对话中提供过，建议在 RAM 控制台轮换或禁用；模型推理不需要它。
- 评测只发送公开政策条款，不发送国家秘密、个人信息、内部材料或真实业务数据。

### 7.7 目标验证与成本折算

- 公开云端点：对话/嵌入 200，嵌入 1024 维；`qwen3.8-max-0902`、`deepseek-v4.1-flash-1017` 快照可用。
- 135 次调用无传输错误，三个模型 outcome 稳定 15/15；数据只含公开条款和公开/合成问题。
- RDS PostgreSQL 18.6 + pgvector 0.8.1.3 小数据验证通过：16 个迁移、54 张表；政务版本边界 2019-05-14→492、2019-05-15→711；知识混合检索命中；冷请求约 1.2s、热请求约 0.3–0.5s。政务条款向量仍是 JSONB + Python 余弦，政策库扩大后可能成为瓶颈。私有化、目标政务云和信创未验证。
- 成本按阿里云北京目录价和实际 tokens 折算：完整评测主口径 **1.073 元**（区间 1.010–1.159），15 条单次约 **0.358 元**；单次问答 max 0.0197 元、flash 0.0012 元、deepseek 0.0028 元；1,000 次约 19.74/1.22/2.82 元；全量嵌入 0.0034 元。
- 未计免费额度、缓存、Batch、税费和优惠；实际账单可能更低。详细口径见 `evaluation/reports/g23-target-cost-20261028.md`。
