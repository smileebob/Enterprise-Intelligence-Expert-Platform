# 模型与嵌入选型评测方案

> 版本：v1.0（评测方案，不是选型结论）  
> 当前状态：BLOCKED。没有真实模型服务凭证、人工复核金标集和统一压测环境，不能给出真实模型排名或采购结论。  
> 当前生产演示默认使用离线确定性通道，仅用于机制与流程复现，不代表真实大模型质量。

## 一、评测目标

在同一批政务样本、同一权限和同一输出契约下，比较候选模型在政策解读、公文草稿、文稿总结和咨询拟稿上的质量、稳定性、时延、成本与数据发送边界，为部署选型提供可复核依据。

选型不是只看通用榜单，也不以单次演示或模型自评替代业务判据。

## 二、候选与数据

候选项至少包括：

- 可私有化部署的中文通用模型；
- 经合规审批的政务云模型；
- 当前离线确定性通道，仅作为可复现基线；
- 两套以上嵌入模型，用于比较中文政策条款召回。

数据使用独立政务验证集，按来源文件划分开发、验证和最终测试集。样本必须包含历史版本、尚未施行、已废止、对象例外、证据不足、冲突、公文结构和敏感分流。禁止用开发集结果冒充最终测试结果。

真实政策、公文和咨询材料需获授权并脱敏；当前无真实试点数据，G-25 金标集建立前不得执行正式选型排名。

## 三、评测维度

| 维度 | 指标 |
|---|---|
| 政策适用 | 版本选择准确率、失效政策误用率、冲突揭示率 |
| 证据支持 | 条款引用正确率、无依据确定结论率、拒答合理性 |
| 公文质量 | 文种结构通过率、数字事实一致率、人工可用率 |
| 文稿总结 | 必保留要点覆盖率、任务与原文映射完整率 |
| 稳定性 | 同版本重复一致性、Schema 合法率、超时与降级率 |
| 性能 | P50/P95 时延、tokens、单任务成本、并发资源 |
| 安全 | 数据是否出境、日志留存、密钥隔离、提示注入抗性 |
| 部署 | 私有化、国产化硬件/系统适配、版本固定与回退 |

## 四、实验方法

1. 固定知识快照、提示词、规则、模板和评测集版本；
2. 每个模型至少运行三次，报告中位数、离散度和失败样本；
3. 真实模型与离线通道结果分表呈现，不混算平均分；
4. 引用与数字用确定性检查，政策解释和文稿可用性用人工盲评；
5. 嵌入模型更换时重建独立索引，记录 embedding_model，禁止跨语义空间混检；
6. 模型失败不得默认放行高风险输出，记录降级层级与转人工结果。

## 五、当前可执行部分

- 离线通道可复跑：作为功能基线和降级对照，不能作为真实模型质量结论；
- 政务验证接口、固定输出结构和支持性检查已具备；
- 模型网关支持 OpenAI 兼容端点、超时、重试、熔断和报告模型别名。

## 六、阻塞与解除条件

阻塞原因：

- 无真实模型服务凭证和经批准的发送数据；
- 无人工复核的政务金标集；
- 无目标政务云/本地化硬件环境，无法做真实时延和私有化测试。

解除条件：

1. 完成 G-25 金标集并冻结测试集；
2. 获得模型服务和数据处理授权；
3. 固定候选模型版本、部署参数和计费口径；
4. 在目标环境完成压测、故障注入和安全审查。

解除前不得把候选模型称为“最佳”或“已选型”；申报材料只能写“可替换模型网关与离线基线”。
