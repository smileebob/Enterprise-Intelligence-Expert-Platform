# 政务公开样本说明

本目录只保存可用于开发评测的公开政策或明确标注的合成样本。

## 公开政策

| 文件 | 政策文件标识 | 官方来源 | 检索日期 | 用途 |
|---|---|---|---|---|
| `public/GOV-REG-711-2019.json` | `GOV-REG-GOV-INFO-DISCLOSURE` | https://www.gov.cn/zhengce/zhengceku/2019-04/15/content_5382991.htm | 2026-10-27 | 2019 修订版本、当前条款引用 |
| `public/GOV-REG-492-2007.json` | `GOV-REG-GOV-INFO-DISCLOSURE` | https://www.gjxfj.gov.cn/gjxfj/zfxxgk/zfxxgkzd/xxgkfgzd/webinfo/2007/04/1590610201936674.htm | 2026-10-27 | 2008—2019 历史有效版本、时效陷阱 |

JSON 中的 `sample_kind` 标明数据类型，`source_hash` 是抽取正文的 SHA-256。样本只抽取条款正文，页面导航和页脚未纳入。`init_gov_demo.py` 为工程演示会将版本置为已审核，但这只用于自动化测试，**不代表真人完成政策复核**；正式演示或评测前必须由领域人员对照官方原文审核。

## 数据规则

1. 不加入未经授权的内部文件、个人信息、工作秘密或国家秘密；
2. 不以公开可访问为理由批量抓取网站；新增样本逐份登记来源和用途；
3. 合成样本必须设置 `is_mock: true`，不得伪造真实发文字号和机关；
4. 政策原文、元数据和人工审核结论分开保存；
5. 删除或撤回来源时，同步处理由它派生的条款、索引、缓存和评测样本。
